# Reglas del Proyecto - Antigravity & Asistentes de IA

## 🚫 Control de Versiones (Git) - REGLA ESTRICTA
- **PROHIBIDO hacer `git commit` automáticamente**: El asistente nunca debe crear commits por su cuenta.
- **PROHIBIDO hacer `git push`**: El asistente nunca debe enviar cambios al repositorio remoto (`origin`, ramas, etc.).
- **Excepción**: Únicamente cuando el usuario ordene de forma expresa y explícita: "haz commit de esto" o "haz push a la rama X".
- **Flujo habitual**: Modificar los archivos localmente, validar con compilación o pruebas, e informar al usuario para que él decida cuándo y cómo versionar y desplegar.
